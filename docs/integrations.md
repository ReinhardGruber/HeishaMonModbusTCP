# Integrations

HeishaMon talks MQTT and JSON/HTTP, so it works with most automation platforms. Ready-made examples:

| Platform | Location |
|---|---|
| Home Assistant | [Integrations/Home Assistant](../Integrations/Home%20Assistant) |
| openHAB | [Integrations/Openhab2](../Integrations/Openhab2), [Integrations/Openhab3](../Integrations/Openhab3) |
| ioBroker | [Integrations/ioBroker_manual](../Integrations/ioBroker_manual) |
| Domoticz | [Integrations/Domoticz](../Integrations/Domoticz) |
| Node-RED | [Integrations/NodeRed](../Integrations/NodeRed) |
| Loxone (Modbus TCP, large board) | [Integrations/Loxone](../Integrations/Loxone), see [Modbus TCP](modbus.md) |

If you do not want to depend on an external system at all, use the [rules engine](rules.md) on the device itself.
